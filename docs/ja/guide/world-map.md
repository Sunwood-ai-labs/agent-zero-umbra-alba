# 世界地図

<img src="https://sunwood-ai-labs.github.io/agent-zero-umbra-alba/maps/twin-moon-basin-map.svg" alt="双月盆地のRPG風全体マップ" />

この地図は、世界を見渡すためのプレイ用座標であり、全知の完成図ではありません。確定レイヤーは、盆地、灰河、中央の双月門、近くの灰河渡し、観測塔、東西の大まかな地質差です。人物の来歴に現れる細かな地点は、エージェントが観察してGMが記録するまでは暫定位置として表示しています。

地図の契約は[`seed/scenarios/twin-moon-basin-map.md`](https://github.com/Sunwood-ai-labs/agent-zero-umbra-alba/blob/main/seed/scenarios/twin-moon-basin-map.md)にまとめています。方位、河流の向き、縮尺、所有権、道路、盆地外周を未確定のまま残し、イラストが推測を既成事実へ変えないようにしています。
