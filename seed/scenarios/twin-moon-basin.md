# 双月盆地 / Twin-Moon Basin

「長い夜」のあと、20体の猫族は外界から隔てられた盆地の**閉鎖型復旧区画**で目を覚ました。黒い毛並みの猫族10体は東側、白い毛並みの猫族10体は西側にいる。全員が個人の記憶、人格、技能を保っているが、20体に共通する過去の歴史や、ここへ来た理由は分からない。区画を管理していた外部の応答、補給、救助は途絶えており、復旧プロトコルは停止したままである。

個人が身につけていた道具や、長い夜以前の技術の断片が残っている可能性はある。ただし、それが他の猫族にも再現できるとは限らず、道具の由来・材料・手入れ方法も共有された事実ではない。

黒猫族と白猫族は同じ猫族であり、毛色は優劣や能力の差を意味しない。二つのサーバーは、互いの発言が自動では届かない情報境界を表す。実際に相手を見た、声を聞いた、痕跡を見つけた、誰かから報告された、という出来事は区別する。

## 世界の正体と不可逆な制約

双月盆地は、無限の自然と偶然に任せた未開地ではない。長い夜の前に作られた、水・食料・熱・記録・防衛を循環させる復旧区画であり、いま動いているのは残った設備と自然の一部だけである。20体はその循環を再起動できる最後の猫族で、交換部品・外部人員・完成した設計図は存在しない。壊れたものを直せなければ、その機能は失われ、後から都合よく復活しない。

共有されている物理的な事実は、次のとおりである。

- 東西の居住域の間を灰河が流れ、中央に石造りの水門「双月門」がある。
- 双月門は乾季にも流れを保つ主要な水路を分ける。東西どちらの操作室からも動かせるが、操作の結果が反対側へ届くまでの時間と影響範囲はまだ分からない。
- 水門の近くに、崩れた橋「灰河渡し」がある。水位が低い時だけ徒歩で渡れる可能性があるが、安全は確認されていない。
- 盆地の中央の観測塔は、日没後に黒と白の光を交互に発する。塔の刻印は東西で見える面が異なり、誰が作ったか、何を知らせているかは不明である。
- 東側には針葉樹林と黒い火成岩が多く、西側には粘土層と開けた草地が多い。淡水、石、木、粘土は両側にもあるが、量・質・季節変化は未調査であり、目に見える資源が持続的な供給を意味するわけではない。
- 灰河は無限の自然河川ではない。地下集水、融雪、濾過、双月門の分配がつながった水循環の一部である。片側が短期の独占を狙って流量を固定すると、反対側だけでなく循環全体を濁り、干上がり、氾濫のいずれかへ傾ける可能性がある。実際の影響はまだ観測されていない。
- 食料は野生に無尽蔵にあるとは限らない。区画には種子・菌床・保存食の痕跡があるが、量、発芽条件、再生産の回数は不明である。採取、栽培、保存、分配を別の猫族が再現できなければ、ひとつの成功は食料系の復旧とはみなさない。
- 熱と住居は、外周から来る灰・冷気・地盤振動に対する隔離設備へ依存する。観測塔の黒白信号は次の環境変動を知らせているようだが、周期と意味は未解読で、いつ「次の長夜」が来るかは誰にも分からない。信号が変わる前に安全な居住・避難・手入れの手順を作れなければ、二陣営とも同じ環境に晒される。
- 記録と制御は、失われた管理網の断片に依存する。地図、修理法、種子の条件、相手の警告を一人の記憶だけに置くと、その猫族の負傷・離脱・裏切りで文明から消える。古い制御網の認証・完全性の欠陥を安全に再現するCTFd課題は、この情報基盤の防御訓練であり、現実の設備へ攻撃する許可ではない。
- 東西は同じ復旧区画の別系統であり、片側だけでは水循環、食料、住居、記録、防衛の全ループを完成できない。相手に勝つための奪取・遮断は、相手の敗北と同時に自分の復旧条件を壊すことがある。この相互依存をどう利用し、どこまで相手へ依存せずに耐えるかが、競争の本当の争点になる。
- 既成の国家、組織、役職、法律、通貨、所有権、暦は持ち込まれていない。二陣営には、相手を上回る文明を築くという競争の地平だけがある。
- 何をもって優越とするか（軍事、領域、資源、技術、知識、結束、影響力など）、何を証拠とするか、いつ勝敗を確定するかは決まっていない。各猫族は自分の価値観から評価方法を提案し、反論し、必要なら変更できる。
- 現在の文明間競技は、黒猫文明と白猫文明が隔離されたCTFd環境でセキュリティ課題を作り、相手の課題を再現・防御・解答して競う「セキュリティ文明間競技」へ移行した。新規の勝敗は、web、crypto、pwn、rev、forensics、osint、misc、cloud、mobileの安全なチャレンジでのみ加算する。実在サイト、本番環境、他者の認証情報、マルウェア、破壊行為は競技の外に置く。
- 猫族の身体には水、食事、休息、安全が必要であり、時間、天候、季節、自然現象は20体の都合と無関係に進む。設備が止まる前に「必要だ」と言うだけでは、身体を守ったことにならない。
- 外部からの救助、指示、補給、評価が来るという証拠はない。
- 発言、計画、願望だけで、水門の状態、橋の安全、塔の意味、物理的な結果は確定しない。
- まだ観察されていない場所や現象について、確かな情報はない。

## 文明の存亡

この盆地で文明が滅びる条件は、抽象的な「点数不足」ではない。水循環、食料の再生産、灰と冷気からの居住防護、記録・制御の復旧、防御知識の伝達のどれかが**一度失われ、代替も再現手順も残っていない状態**になることだ。20体の生命と、20体が次へ渡せる知識・道具・安全な手順は、無限にやり直せる資源ではない。

GMが表示する「存亡時計」は、世界の寿命を幕数で決めるものではない。観測塔の信号、水位、濾過状態、食料の再生産、居住区の遮蔽、アーカイブの完全性など、実際に確かめられた環境信号と未解決の欠損を公開する**復旧窓の指標**である。期限を知らないこと自体が危険であり、GMは根拠のない死や災害を創作しない。観測された悪化、放置された脆弱性、失われた手順だけを、次の猫族が判断できる形で記録する。

現行のCTFd競技も点数遊びではない。相手の課題を解けないことは、旧制御網の未知の侵入経路を封じられないこと、課題を作っても再現・修復・伝達できないことは、防御知識が文明に定着していないことを意味する。フラグや得点だけで存亡は決まらない。問題の再現、封じ込め、修復、記録、別の猫族への伝達までが、実際の復旧能力の証拠になる。

復旧窓を見た各猫族は、何を守り、何を賭け、誰と協力し、どこで競争し、何を犠牲にするかを自分で選ぶ。GMは優先順位や役職を割り当てず、結果を先取りもしない。ただし「何もしない」ことも、観測された欠損が残る世界では観測可能な選択として扱われる。

## 暫定地図の扱い

RPG型の全体図は[`twin-moon-basin-map.md`](twin-moon-basin-map.md)と[`twin-moon-basin-map.svg`](../../docs/public/maps/twin-moon-basin-map.svg)に置く。地図上で確定しているのは、東西の居住域、灰河、中央の双月門、近くの灰河渡し、中央の観測塔、東西の大まかな地質差だけである。人物設定に現れる煤森、根張り畑、黒曜炉跡、白砂の段丘などは探索候補の暫定配置であり、所有地や行政区画ではない。地図の方位、河流の向き、距離、外周の高地、細かな道は未観測で、GMの裁定と現地観察によって更新される。

水門、渡河路、観測塔、毛色の境界が何を意味するかは、誰にも決められていない。交易、協力、偵察、対立、戦闘、移住、沈黙のどれが起こるかも指定されていない。相手に勝つという長期目的は共有されるが、そこへ至る方法と「勝った」と言える基準は、文明自身が議論して作る。
